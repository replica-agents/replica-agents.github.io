Abstract

PDF documents integrate poorly with the web. To improve accessibility, they are frequently converted into HTML. Existing approaches for document-to-HTML conversion largely focus on retaining text and logical structure. However, the document's physical structure is not preserved. Visual cues such as color, font style are overlooked and design aspects such as content positioning are ignored.

To address these shortcomings, we introduce REPLICA, an agentic document-to-HTML framework that generates visually faithful, layout-aware, and semantically enriched HTML which we refer as Fid-HTML. Our approach generalizes across diverse document types and multiple languages. For systematic evaluation, we introduce VFDR-Bench spanning 15 languages, and 15+ document types.

REPLICA achieves 93% visual fidelity, outperforming strong baselines including GPT-5 and Gemini 3 Pro. Notably, REPLICA with Qwen3-VL-8B achieves a 39% gain overall as compared to Qwen3-VL-30B, despite being 3.75× smaller and operating at comparable inference time, highlighting the effectiveness of structured agentic design over brute-force scale. By preserving visual integrity and semantics in multilingual documents, REPLICA unlocks new possibilities for design-preserving translation, scalable access, and structured search.

Introduction

PDFs preserve documents with precise control over layout, typography, and visual styling. Yet this fidelity often vanishes when converted for the web. Traditional OCR engines process page images to recover plain text, discarding layout, typography, and styling. Other workflows convert PDFs to alternate formats such as Markdown. PDF parsers extract text or lightweight markup directly from the PDF’s internal structure but still lose structural hierarchy (e.g., multi-column layouts), fine-grained formatting, and much of the visual and spatial identity.

To overcome these limitations, we introduce REPLICA, an agentic framework that generates Fid-HTML - semantically enriched, layout-aware HTML preserving text, logical structure, physical layout, and visual fidelity. Beyond plain rendering, it embeds semantic layout classes and spatial cues, directly addressing the layout, typography, and styling losses of prior methods.

Key Contributions:

  • Fid-HTML, a new web-native format that represents documents in high-fidelity HTML, which is both semantically enriched and preserves visual and spatial fidelity.
  • REPLICA, an agentic framework for end-to-end page reconstruction that segments, localizes, assembles, and refines content to produce Fid-HTML.
  • VFDR-Bench, a benchmark for evaluating fidelity and robustness in document-to-web conversion.
  • A suite of new evaluation metrics: Global Position Score (GPS), Local Position Score (LPS), and Visual Fidelity Score (VFS).

Downstream Applications of REPLICA enabled by Fid-HTML: A Layout-Preserving Document Translation, B Document Preservation, C Indexing & Searchability, D Grounded Document Intelligence, E Semantic Document Chunking for RAG, F Position-Aware Document Retrieval.

Agentic Framework Approach

A divide-and-conquer strategy centered on four key stages.

Overview of REPLICA: The agentic framework constructs a hierarchical semantic layout (1 Segment), generates sub-HTML fragments via routed specialist-agents (2 Localize), composes them with position- and reading-aware assembly (3 Assemble), and iteratively refines visual fidelity through font optimization, background restoration, and VLM-based reflection (4 Refine).

1 Segment

Hierarchical Semantic Layout Detection: We determine whether the document is digital or scanned. For scanned pages, we utilize layout detection ensembles (e.g., DocLayout-YOLO, Hi-SAM). A Labeling Agent assigns semantics using Set-of-Mark prompting, while a Grouping Agent maps parent-child relations to construct a comprehensive layout graph \( \mathcal{T}_{\text{layout}} \).

2 Localize

Layout-Aware HTML Generation: The layout tree is parsed, and a Router Agent evaluates modalities. It delegates tasks to Specialist Agents (Text, Table, Image, Form, List, Equation). Tools like OCR and Table Structure Recognition are explicitly invoked to create accurate, isolated sub-HTML elements dynamically.

3 Assemble

Position- and Reading-Aware Merge: Localized sub-HTMLs are merged bottom-up. Standard spatial heuristics can fail on complex multi-columns, so a Reading-Order Agent evaluates text flow and continuity to enforce an accurate, natural layout structure seamlessly.

4 Refine

Visual Fidelity Enhancements: A Reflection Agent loops over rendered HTML outputs versus the source. We apply bounded font-size optimization, OpenCV-based background inpainting, and targeted CSS injections to correct perceptual artifacts the standard browser engine misaligns.
