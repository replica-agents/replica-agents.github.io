Why visual fidelity actually matters

Every word survived. The meaning didn't.

Naming the gap

OCR recovers content. It loses structure and style.

What it says

Content

The words themselves — characters, tokens, language. OCR already does this well.

How it's organised

Structure

Titles, columns, nested lists, tables, figures, reading order — the logical and physical layout.

How it looks

Style

Typography, colour, weight, spacing, backgrounds — the rendered appearance on the page.

Visual fidelity is the umbrella for the last two — and it is exactly what existing pipelines discard by design.

Why not just prompt a bigger model?

The failure is architectural, not a matter of scale

Single-pass VLM

One forward pass must do everything

  • Detect regions, read text, order them, and style them — jointly, with no geometric grounding.
  • No deterministic control: hallucinated structure, unstable CSS.
  • Never sees its own render, so visual errors cannot be caught.
  • Degrades sharply beyond English & Chinese.
Agentic decomposition

Specialised competencies, coordinated

  • Deterministic tools handle geometry: detectors, OCR, reading order, font fitting.
  • Reasoning agents validate, route, group, and reflect.
  • The system renders and looks at its own output, then repairs it.
REPLICA + Qwen3-VL-8B beats Qwen3-VL-30B by 39% — at 3.75× smaller and comparable inference time.
The task decomposes naturally

Four questions → four stages

1

Segment

"Where are the pieces?"

Detect and hierarchically organise titles, paragraphs, tables, figures into a layout tree.

2

Localize

"What does each say?"

Route every region to a specialist agent that emits styled sub-HTML.

3

Assemble

"How do they fit?"

Merge fragments bottom-up, preserving containment and global reading order.

4

Refine

"Does it look right?"

Render, compare against the source, and repair until it visually matches.

Four different competencies → we build agents that reason and tools that execute around each. That is what makes it agentic.
The pipeline, at a glance

REPLICA end-to-end

Stage 1 of 4

Segment — find the pieces

1Segment
2Localize
3Assemble
4Refine
  • Document-type analysis (tool). Digitally-born → read structure directly from PDF primitives. Scanned → infer from visual geometry.
  • Detector ensemble (tool). DocLayout-YOLO + IndicDLP-YOLO + Hi-SAM, fused by IoU merging.
  • Labeling agent. Set-of-Mark prompting assigns semantic types and catches mis-segmented or mixed-content blocks.
  • Grouping agent. Builds a directed layout graph from containment, reading order and semantic compatibility → constrained into a tree.
Detectors localise well but cannot reason. Agents fix borderless tables, multi-column wraps and nested structures before generation — preventing error propagation.
Stage 2 of 4

Localize — describe each piece

1Segment
2Localize
3Assemble
4Refine
  • Router agent. Sees crop + bbox + label + structural constraints, and overrides the upstream label when the visual contradicts it — e.g. an equation tagged as text.
  • Six specialist agents: text, table, image, form, list, equation — each with its own generation strategy.
  • Conditional tool use. OCR only for low-res or script-complex crops; table structure recognition only for merged headers or irregular grids; TexTAR for font attributes.
  • Colour-coded Set-of-Mark prevents index leakage into the generated HTML.
Nodes are conditionally independent → sub-HTML generation is fully parallelisable. Routing accuracy 0.97, sub-HTML validity 0.96.
Stages 3 & 4 of 4

Assemble, then Refine against the render

1Segment
2Localize
3Assemble
4Refine
3

Assemble

  • Position-aware merge (tool): bottom-up over the layout tree, preserving containment, nesting and spatial alignment.
  • Reading-order agent: spatial sorting alone fails on multi-column pages and floats — ordering is computed from textual continuity and contextual coherence.
  • Reading order accuracy 0.98 (Kendall-τ).
4

Refine — the closed loop

  • Font-size optimisation (tool): bounded search for maximal non-overflow scales.
  • Background restoration (tool): page-level colours, shading and overlays restored via CSS layering.
  • Reflection agent: renders the HTML, compares it to the source image, and injects targeted CSS fixes — up to 5 iterations.
Why this matters: PDF rendering and the browser's CSS box model simply differ. Fidelity has to be checked on the render, not on the markup.

What FID-HTML unlocks

Being honest about the edges

Where REPLICA still falls short

Single-page only

Multi-page structures — spanning tables, figures, continued sections — can fragment across page boundaries.

Font identification

Bold, italic, underline and colour are recovered reliably; exact multilingual font families remain unresolved.

Rendering cost

The refine loop's repeated browser rendering adds real latency versus a single forward pass.

High-resource skew

The benchmark still leans toward well-structured layouts and higher-resource scripts.
